# 从请求调度到 RL rollout：四篇经典把系统串起来

主读 Orca；选读 PagedAttention、SGLang 与 HybridFlow。沿着调度、KV 内存、程序执行和训练生成切换，理解 agent serving 与 RL 基础设施。

每天推荐 1 篇主读与 2–4 篇选读；候选不等于已读，无需一天读完。优先建立系统基础，再逐步连接当前的 agent serving 与 RL infra 工作。

[[CN/reading/index|全部推荐]] · [[CN/reading/roadmap|学习路线]] · [订阅 RSS](https://shikicloud.github.io/MLSys/reading.xml)

## 主读 · Orca: A Distributed Serving System for Transformer-Based Generative Models

- **年份 / 发表信息：** 2022 · OSDI 2022 · [原文](<https://www.usenix.org/conference/osdi22/presentation/yu>)
- **核心贡献：** 把调度粒度降到一次生成迭代，让完成的请求退出、等待的请求进入，并用 selective batching 处理不同算子的批处理需求。
- **与当前工作的关系：** 为 agent 请求调度和 rollout 长短序列混跑建立基线：先理解一次 decode step 如何接纳请求，再看跨轮优先级与 KV 驻留。
- **阅读建议：** 值得精读。第一轮用约 25 分钟看问题、调度设计和实验设置，画出两个长请求与一个短请求的时间线；暂时跳过底层实现细节。
- **前置知识：** 知道自回归生成逐 token 进行；能够区分 prefill 和 decode 即可。
- **局限与注意：** 论文面向当时的模型和硬件；它是理解迭代级调度的起点，不直接证明多轮工具调用的最优调度策略。

## 选读 · Efficient Memory Management for Large Language Model Serving with PagedAttention

- **年份 / 发表信息：** 2023 · SOSP 2023 · [原文](<https://arxiv.org/abs/2309.06180>)
- **核心贡献：** 用逻辑块到物理块的映射管理动态增长的 KV cache，减少碎片，并支持共享与写时复制。
- **与当前工作的关系：** 解释为什么可接纳的 batch 不只由计算决定，也由 KV 内存布局决定；为讨论前缀保留、驱逐和 CPU offload 提供内存管理基础。
- **阅读建议：** 值得精读，可作为下一篇主读。先读 block table、共享与 copy-on-write，手画两个共享前缀请求的缓存布局；首轮不必钻 attention kernel。
- **前置知识：** 知道每生成一个 token 会增加 KV 状态；先了解 Orca 的动态批处理问题。
- **局限与注意：** 分页管理解决内存分配问题；哪些会话应该保留、工具等待多久以及跨设备迁移，仍需单独的策略与评估。

## 选读 · SGLang: Efficient Execution of Structured Language Model Programs

- **年份 / 发表信息：** 2024 · NeurIPS 2024 · [原文](<https://proceedings.nips.cc/paper_files/paper/2024/hash/724be4472168f31ba1c9ac630f15dec8-Abstract-Conference.html>)
- **核心贡献：** 联合设计语言程序前端与运行时，以 RadixAttention 复用 KV 前缀，并优化结构化生成。
- **与当前工作的关系：** 把程序结构与缓存命中联系起来，适合反思多轮 agent 的共享历史、分支生成和前缀优先保留。
- **阅读建议：** 选择性精读 RadixAttention 与程序执行部分。用一个有工具调用的会话画前缀树，标出哪些调用能够共享 KV。
- **前置知识：** 前缀缓存、树结构，以及 PagedAttention 的逻辑块和物理块概念。
- **局限与注意：** 论文描述原始系统设计；今天的 SGLang 已有后续演进，论文机制与当前实现要分开核对。

## 选读 · HybridFlow: A Flexible and Efficient RLHF Framework

- **年份 / 发表信息：** 2025 · EuroSys 2025 · preprint 2024 · [原文](<https://i.cs.hku.hk/~cwu/papers/gmsheng-eurosys25.pdf>)
- **核心贡献：** 结合单控制器与多控制器执行方式，并用 3D-HybridEngine 降低策略模型在生成与训练之间切换分片的成本。
- **与当前工作的关系：** 与 rollout worker、训练到推理的权重同步和并行配置切换直接相连；有助于区分控制开销、数据搬运与 GPU 计算。
- **阅读建议：** 先浏览整体数据流，稍后精读。画 generation → preparation → training 的 GPU 分配与权重流向，再联系自己的 rollout 路径。
- **前置知识：** RLHF/GRPO 训练循环、数据并行和张量并行；不熟悉时先读路线中的 Ray、Megatron-LM 与 ZeRO。
- **局限与注意：** 会议版为 2025 年，预印本为 2024 年；原始 RLHF 评估不能直接外推到含长时间工具调用的 agent rollout。
